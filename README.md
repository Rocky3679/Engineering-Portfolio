### Automotive Virtual Lab (In Development)

Cloud-based embedded firmware modules designed to run on lightweight browser simulators without requiring physical hardware benches:

- **Virtual-BMS-Coulomb-Counting** *(ANSI C / Google Colab)*  
  Discrete-time battery State-of-Charge (SOC) tracking using current integration, resting Open Circuit Voltage (OCV) calibration, and high-temperature derating cutoffs.
- **ESP32-SVPWM-Motor-Control** *(FreeRTOS / Wokwi)*  
  Clarke and Park transformations driving a 6-sector Space Vector PWM generator with complementary outputs and shoot-through protection dead-time.
- **Virtual-CAN-EV-Telemetry** *(ESP32 TWAI Driver / Python)*  
  In-vehicle communication testbench broadcasting synthetic battery/inverter metrics decoded against a custom `.dbc` matrix.
